# TP4 — Application JavaScript

## Présentation
Ce projet consiste à développer une application JavaScript organisée en modules, utilisant plusieurs fichiers JSON liés entre eux.

## Structure du projet
- `index.html` : page principale.
- `css/style.css` : mise en forme.
- `data/` : données JSON des clients, produits et commandes.
- `js/` : logique JavaScript, gestion de l'état, chargement des données, sélecteurs et affichage.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- JSON
- Git et GitHub

## Lancement
Ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de Visual Studio Code.
